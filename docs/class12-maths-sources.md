# Class 12 Maths — which questions came from a real board paper

Chapter 1 has a file of its own, `docs/class12-maths-relations-and-functions-sources.md`,
because every one of its fifteen questions is sourced and each needs its paper
and question number named. This file covers the **other twelve chapters**, where
the pass is partial, and says plainly how partial.

**The rule, unchanged:** a question is tagged with a year only if it was read
verbatim out of a full CBSE **Mathematics (041)** board question paper for that
year. Nothing is tagged from a compilation, a coaching sheet, or memory. A
question without a tag is not a lesser question — `source` is optional, and an
untagged question is complete. It is the *claim* that has to be earned.

## The corpus

70 full Class XII Mathematics board papers — the papers the class actually sat,
not sample papers — from `https://www.cbse.gov.in/cbsenew/question-paper.html`:

## Why some chapters are thin

The papers are read by extracting their text, and **mathematical notation is the
first thing that extraction loses**. A question that reads

> The principal value of $\sec^{-1}$ ___ $+ 2\operatorname{cosec}^{-1}$ ___ is :

cannot be tagged, because what it actually asked is no longer on the page. The
same is true of most integrals, most matrices given entry by entry, and every
question whose answer options are fractions or surds.

So the chapters that come out well are the ones whose questions are carried by
**words and whole numbers** — Relations and Functions, Determinants,
Application of Derivatives. The ones that come out thin are those carried by
**symbols** — Integrals, Vector Algebra, Linear Programming.

Recovering the rest means reading the PDFs as pages rather than as text. That is
the next pass, and it is a different kind of work, not more of this kind.

## Changes of form, stated plainly

- Some questions that are MCQs or short-answer in the paper are asked here as
  **numeric entry**, because the app grades a typed number directly. Where the
  paper asked for a set or a pair of values, the question asks for something
  that identifies it — the size of an equivalence class, the positive root — so
  the work a student does is unchanged.
- Assertion–Reason options are written out in full rather than abbreviated.
- Where a paper offered an "OR" pair, only the half used is asked.
- Maths is re-typeset in KaTeX. No question's content was changed.

## Answers were recomputed, never copied

Every numeric answer here was worked out independently rather than taken from a
key, and several were checked numerically. Three worth naming:

- $\int_0^{\pi/2}\lvert\sin x - \cos x\rvert\,dx$ was integrated by hand to
  $2\sqrt2 - 2$ **and** evaluated by Riemann sum to $0 \cdot 8284271$ — they agree.
- $\int_0^{\pi/4}\log(1 + \tan x)\,dx = \frac{\pi}{8}\log 2$, likewise confirmed
  numerically as $0 \cdot 2721983$.
- For $f(x) = x + \frac1x$, the local **maximum** value $-2$ is smaller than the
  local **minimum** value $2$. That is not a slip; the two stationary points lie
  on opposite branches of the curve, and the solution says so, because a student
  who thinks it is a misprint has understood the question correctly and the
  answer wrongly.

## If a tag looks wrong

Correct it in the chapter's JSON under `content/class12-maths/` and re-run
`node scripts/seed-library.mjs content/class12-maths` — that replaces the
library copy. Every question also has a **Source** field in the editor, so a
teacher can fix their own copy directly; clearing the field removes the chip.
