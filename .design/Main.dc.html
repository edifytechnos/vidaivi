Let R be the relation on the set A = {1, 2, 3, 4} defined by R = {(a, b) : |a − b| is even}. Which of the following is true?
Answer expected
Multiple choice
Marks
1
A R is reflexive but not symmetric
B R is an equivalence relation Correct
C R is symmetric but not transitive
D R is neither reflexive nor transitive
Explanation
Shown after answering

Reflexive. For every a ∈ A, |a − a| = 0, which is even, so (a, a) ∈ R.

Symmetric. If |a − b| is even then |b − a| is the same value, so (b, a) ∈ R.

Transitive. If |a − b| and |b − c| are both even, a, b and c share the same parity, so |a − c| is even too.
