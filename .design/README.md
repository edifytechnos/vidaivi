# Design canvas source

Artboards for the authoring redesign, published as a Claude Design canvas:
https://claude.ai/code/artifact/2df31b17-68dc-4d51-bcad-3ac8aa44dbfb

Each `*.dc.html` is one artboard; `canvas.json` places them. The seeded
output (`vidaivi-authoring-redesign.html`, ~2.5 MB — it embeds the canvas
editor) is gitignored and rebuilt from these sources.

Colours, type and component specs are lifted from `src/style.css` so the
mockups match the shipped app exactly.
